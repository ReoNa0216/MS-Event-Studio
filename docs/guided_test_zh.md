# MS Event Studio 最终人工验收操作卡

这不是测试团队清单。自动化、异常注入、键盘、Windows 四档缩放和大型只读源回归都已经
完成。你只需要在 **Apple Silicon Mac + Retina 屏幕**上判断三件事：界面是否清楚、操作
是否顺手、结果是否符合科研直觉。

正常用时约 15 分钟，不含首次分析源文件的等待时间。

## 先准备好

- 一台 Apple Silicon Mac，使用内置 Retina 屏幕和鼠标或触控板。
- 一份可丢弃的 MS Event Studio 项目副本。没有项目副本时，也可以准备一个中小型 MS
  TXT 源和一个空文件夹；不要用唯一的生产项目做验收。
- 不需要重新计算 SHA-256，不需要再读 7.38 GiB 大文件，也不需要故意制造失败。

## 1. 下载并打开候选

1. 打开 [GitHub Actions 构建 31678141049](https://github.com/ReoNa0216/MS-Event-Studio/actions/runs/31678141049)。
2. 在页面底部 **Artifacts** 中下载 `ms-event-studio-macos-arm64`。
3. 解压下载文件，再解压其中的 `MS-Event-Studio-0.3.0-dev1-macos-arm64.zip`。
4. 打开 `MS-Event-Studio.app`。这是未公证的测试候选；若 macOS 阻止首次启动，右键应用
   选择 **打开** 并确认。若仍被阻止，到 **系统设置 → 隐私与安全性** 选择 **仍要打开**。

通过标准：只出现一个 MS Event Studio 窗口；没有终端、旧 Tk 界面或第二个应用窗口；
标题、按钮和峰形图在 Retina 屏幕上清晰，没有发虚。

## 2. 打开项目

有项目副本时走最短路径：

1. 点击 **打开项目**。
2. 选择项目文件夹。
3. 等待工作区出现。

没有项目副本时：

1. 点击 **新建项目 → 选择文件…**，选择测试 TXT。
2. 分析完成后填写项目名；起点和终点保持在页面给出的可用范围内。
3. 点击 **选择位置…**，选择一个新的空位置，再点击 **创建项目**。

通过标准：分析时窗口仍可响应；页面只显示文件名，不显示完整磁盘路径；成功后直接进入
工作区。

## 3. 完成一次真实审阅

1. 看左侧当前事件，再看右侧图中被高亮的峰。确认二者明显对应。
2. 点击 **更多证据**，判断 PC34、m/z、质量误差等信息是否容易找到和理解。
3. 给当前事件点击 **保留**。
4. 给自动前进后的下一个事件点击 **待定**。
5. 点击 **撤销**，再点击 **重做**。

通过标准：每次保存都有明确反馈；保存后会前进到下一个未审阅事件；撤销和重做的结果
一眼可见。你不需要阅读说明才能知道当前事件是什么、应该在哪里作判断。

## 4. 试一次峰顶调整

只在可丢弃的项目或副本中操作：

1. 选中一个自动事件，点击 **重新定位峰顶**。
2. 在允许区间内点一个邻近峰顶，先查看候选预览。
3. 点击 **取消**，确认项目没有改变。
4. 再做一次预览，这次点击 **应用候选**，然后点击 **撤销**。

通过标准：进入编辑后允许范围、候选位置、应用和取消都很清楚；第一次点击只是预览，
不会直接改项目；取消和撤销都符合直觉。

## 5. 看一次范围预览并导出

1. 点击 **项目设置 → 修改分析范围**。
2. 把起点或终点小幅调整，点击 **计算影响**。
3. 看完影响数量后点击 **取消**，不要应用新范围。
4. 点击 **导出结果**，保持默认的 **审阅结果**。
5. 选择一个新的 CSV 文件名并导出。

通过标准：范围预览能说明“会发生什么”；取消后项目范围不变；导出结束后能看到文件名和
行数，目标位置确实出现 CSV。

## 6. 专门看 Retina 布局

1. 把窗口缩到系统允许的最小尺寸，再恢复到较大尺寸。
2. 打开 **修改分析范围** 对话框，滚动到最底部。
3. 检查顶栏、左侧证据、峰标签、滚动条和底部按钮。

通过标准：没有文字被截掉、按钮互相压住、横向滚动或模糊缩放；对话框底部操作始终能
滚动到并点击；鼠标或触控板操作没有明显卡顿。

## 7. 关闭并重开

关闭应用，重新启动，再从最近项目中打开刚才的项目。

通过标准：刚才的 **保留/待定** 状态仍在；应用能正常关闭，不残留第二个窗口。
