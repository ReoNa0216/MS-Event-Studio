# MS Event Studio：Windows 验收操作卡

这次只验收 **Windows 版本**。你不需要运行命令、计算哈希、查看 GitHub Actions、修改
显示缩放，也不用重新分析 7.38 GiB 大文件。像平时一样使用软件即可，预计 10 分钟左右。

请使用项目副本，不要在唯一的生产项目上测试保存、调峰和撤销。

## 1. 启动并打开项目

1. 打开 `dist\windows\MS-Event-Studio`。
2. 双击 `MS-Event-Studio.exe`；不要单独复制 EXE。
3. 点击 **打开项目**，选择项目副本所在的文件夹。

看到一个正常的 MS Event Studio 窗口、事件列表和信号图即可。不能出现黑色终端窗口、旧版
Tk 界面或第二个应用窗口。页面可以显示文件名，但不应显示完整磁盘路径。

如果没有现成项目副本，也可以点击 **新建项目**，选择一个中小型 MS TXT，等分析完成后
创建到新的空位置。

## 2. 审阅两个事件

1. 看左侧“当前事件”，确认右图高亮的是同一个峰。
2. 点击 **保留**，确认软件自动前进到下一个事件。
3. 对下一个事件点击 **待定**。
4. 点击一次 **撤销**，再点击一次 **重做**。

通过标准：保存反馈明确；自动前进、撤销和重做的变化都能一眼看懂。

## 3. 看懂信号图

请直接观察，不用逐个数：

- 峰顶时间只显示简短数字，没有白色大标签框；
- 数字不会因为鼠标移到不同峰上就换一批；
- 小标记不会遮住真实峰形；
- “事件筛选”等工具文字清楚可读；
- “上一事件 / 下一事件”和下面的“当前事件”之间有明确间隔；
- 没有按钮互相挤压、文字被截断或横向滚动条。

## 4. 只在确有必要时调整峰顶

“重新定位峰顶”不是每个事件都要做。它只用于：**自动标记明显没有落在这条局部曲线的真实
最高点上**。如果当前事件已经对准峰顶，就不要为了完成测试而强行修改；换一个明显偏离的
自动事件，找不到也可以直接反馈“没有合适的例子”。

1. 选中一个自动事件，点击 **重新定位峰顶**。
2. 图应自动放大到这个事件附近。青色虚线只是科学规则允许的位置范围，不代表应该选中点。
3. 以局部曲线本身为依据：点击曲线真正达到最高处的位置。系统会再吸附并校验真实扫描点。
4. 查看“原位置 → 候选位置”预览；此时项目还没有被修改。
5. 先点击 **取消**，确认回到原来的图窗且峰顶没变。
6. 如有合适例子，可再次预览并点击 **应用候选**，然后点击 **撤销**。

通过标准：放大后能看清实际曲线；标记没有盖住峰顶；你能凭峰形判断该点哪里；取消和撤销
符合直觉。如果仍然看不出依据，不要反复试，直接告诉我。

## 5. 预览范围并导出 CSV

1. 点击 **项目设置 → 修改分析范围**。
2. 小幅调整起点或终点，点击 **计算影响**。
3. 看完影响数量后点击 **取消**，不要应用新范围。
4. 点击 **导出结果**，保持默认的 **审阅结果**，保存为一个新的 CSV。

通过标准：取消后项目范围不变；目标位置出现 CSV；页面显示的文件名和行数合理。

## 6. 缩小窗口并重开

1. 把窗口拖小，再恢复到较大尺寸。
2. 确认文字和按钮没有互相覆盖，底部操作都能点到。
3. 关闭软件，重新启动，并从最近项目中打开刚才的项目。

通过标准：刚才保存的审阅状态仍然存在，程序能正常关闭和重开。
