# MS Event Studio 0.4.1：Windows 验收操作卡

这份指南先服务 Windows 用户。预计 8–12 分钟，不要求懂代码，也不用重复自动化测试。
请使用一个你熟悉、体积不太大的 MS 原始文件；旧格式测试项目请不要复用，0.4.1 需要重新建项目。

## 1. 启动

1. 从公开 Release 下载 `MS-Event-Studio-0.4.1-windows-x64.zip`；维护者本机复测也可以直接使用 `dist/windows/MS-Event-Studio/MS-Event-Studio.exe`。
2. 完整解压 ZIP，进入 `MS-Event-Studio` 文件夹，双击 `MS-Event-Studio.exe`。
3. 观察欢迎页出现速度。如果明显要等很久或先出现空白窗口，请记下大约等待了几秒。

通过标准：程序正常出现欢迎页，没有命令行窗口、报错框或长时间空白。

## 2. 新建项目与两个科学参数

1. 点击“新建项目”。
2. 确认默认值是：
   - 细胞事件 marker m/z：`760.5851`
   - 相邻事件提示阈值：`0.60 s`
3. 普通验收请保持默认值。除非已经为另一个 marker 准备了真实对照数据，否则不要把修改
   marker 当作常规操作；软件能提取该 m/z 不代表它已经被证明适合识别细胞事件。
4. 选择 MS 原始文件并等待分析完成。
5. 选择项目保存位置并创建项目。

通过标准：两个参数容易找到、说明能看懂；项目创建成功；原始 MS 文件没有被改名、移动或覆盖。

## 3. 当前窗口批量保留

1. 打开包含多个未审阅事件的窗口。
2. 看左侧“审阅进度”下方的提示，例如“本窗口有 10 个未审阅事件：8 个可以批量保留；
   2 个与相邻事件距离过近，需要逐个判断”。
3. 点击“批量保留这 8 个事件”。
4. 确认距离过近的事件仍留给人工判断，其他未审阅事件变为已保留。
5. 点击一次“撤销”，确认整批一起恢复；再点“重做”，确认整批一起回来。

通过标准：不会改动已经保留、排除或待定的事件；不会批量处理“自动识别时”或“按当前峰顶”
任一项显示“与相邻事件距离过近”的事件。选中一个事件时，“核心证据”下方应分别显示这两项。

## 4. 信号图

依次点击几个峰，观察：

- 当前事件有独立的紫色轮廓，原来的未审阅/保留/排除/待定形状和颜色仍能看见；
- 图底部有分钟刻度；峰靠近窗口边缘时仍留有少量上下文；
- 数字时间标签是小号、透明背景的纯数字，不会因为移动鼠标而变化；
- 点击另一个事件时，当前事件数字会优先显示。为了避免重叠，附近一个次要数字可能被替换，这是预期行为。

## 5. 两种导出

### 审阅结果

1. 点击“导出结果”→“审阅结果”。
2. 点击“选择文件…”，选择文件名和位置。
3. 导出后确认得到一个 `.csv` 文件。

### 完整审计数据包

1. 切换到“完整审计数据包”。
2. 选择一个普通保存位置，例如“文档”或一个已有文件的目录；**不要预先创建空文件夹**。
3. 导出后确认应用在该位置新建了一个数据包文件夹，里面有 3 个文件。

通过标准：取消选择时不写文件；导出失败时不留下半成品，也不删除目录中已有内容。

## macOS 测试者补充

macOS Apple Silicon 用户执行同样的第 1、2、4、5 节即可，重点确认“审阅结果”在系统保存窗口
选择文件名后能得到 `.csv`，以及“完整审计数据包”只需选择保存位置。请同时说明 macOS 版本和
芯片型号。Windows 维护者不需要代测这一节。
