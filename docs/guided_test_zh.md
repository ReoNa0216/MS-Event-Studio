# MS Event Studio 0.3.0.dev1 中文引导验收

本文用于 `0.3.0.dev1` WebView 候选的最终用户 UAT。自动化已经覆盖主要状态、错误回滚、
键盘交互和标准浏览器视口；本轮请重点判断真实任务是否清楚、证据是否足以做决定，以及
项目重开和导出结果是否符合预期。

> 候选状态：Windows 原生 100%、125%、150% 与 200% 缩放均已完成 pre-UAT；
> macOS ARM64 Actions 构建与 Cocoa 隐藏启动检查已通过。macOS Retina 可见界面和鼠标
> UAT 仍待 Apple Silicon 真机验收，完成本文前不得宣布 Phase 2R 退出。

## 1. 测试前准备

1. 只使用负责人提供的候选包，并记录版本、候选包 SHA-256、操作系统、显示缩放和测试
   时间。Windows 包必须保留完整的 `MS-Event-Studio` 文件夹，不能只复制 EXE。
2. 准备一份你有权使用的 MS TXT 测试源。原始源应保持只读；不要改名、移动或编辑。
3. 为本轮准备独立的空项目位置和独立导出位置。不要在源数据目录或 LMA Studio 项目
   目录内创建项目，也不要覆盖任何 LMA `ms_events.parquet`。
4. 涉及审阅、峰顶、范围或撤销历史的测试会写入 MS Event Studio 项目。请使用一次性
   项目或项目副本，不要直接拿唯一的生产项目做验收。
5. 如安排大型真实源测试，先记录源文件的大小、修改时间和 SHA-256；测试后再次核对。
   未经负责人安排，不必为了本轮验收重复读取大型资产。

发生问题时先保留现场，不要手动修改项目内部文件。

## 2. 启动与欢迎页

1. 启动候选。预期只出现一个 MS Event Studio WebView 窗口，没有旧 Tk 审阅页或额外
   控制台窗口。
2. 检查欢迎页的 **新建项目**、**打开项目** 和“原始 MS 文件始终保持只读”说明。
3. 若有最近项目，确认页面只显示便于识别的名称，不显示原始文件或项目的绝对路径。
4. 仅用键盘按 Tab 浏览一轮：焦点应始终清楚可见；按 Enter 可打开当前按钮；按 Esc
   可关闭允许取消的对话框，并把焦点还给原入口。

## 3. 新建项目

1. 点击 **新建项目**，再点 **选择文件…** 选择测试源。应用应自动开始检查，并持续
   更新已读字节、扫描数量和进度，窗口不能假死。
2. 建议先做一次取消：检查过程中点击 **取消分析**。预期最终显示已取消，源文件未变，
   可以点击 **重新分析**；取消后不得留下半成品项目。
3. 重新分析并等待完成。核对显示的文件名、可用时间范围、扫描数量和文件大小是否合理。
   页面不应暴露绝对路径。
4. 填写项目名称和闭区间起止时间。起点可以等于终点，但不能晚于终点；超出可用范围或
   非法输入应给出清楚提示。
5. 点击 **选择位置…** 选择独立目标，再点击 **创建项目**。预期创建期间控件不可重复
   提交；成功后直接进入事件审阅工作区，不需要再次打开项目。

## 4. 浏览工作区与证据

1. 首次进入时应选中第一个未审阅事件。左侧显示审阅进度、峰顶时间、状态、来源和核心
   证据；点击 **更多证据** 可展开附加信息。
2. 使用 **上一事件**、**下一事件**、图中标记和事件列表切换选择。列表、图中高亮和左侧
   证据必须指向同一个事件。
3. 调整起点与窗宽，使用上一/下一窗口，再分别检查事件筛选、线性/对数、标签开关。
   信号线和事件标记应保持分层，最高峰、边缘峰和密集峰的标记或说明不能被裁切、遮挡。
4. 将窗口缩到可用的较小尺寸，确认可以自然换行或纵向滚动，关键证据和主要操作仍然
   可达，页面不能出现横向溢出。

## 5. 审阅、备注与历史

1. 在 **操作备注** 中输入一段文字，并输入字母 `a r p u`。文本框有焦点时，这些字母
   只能作为文字输入，不能触发审阅快捷键。
2. 离开文本框，依次用按钮或 A/R/P 将测试事件设为 **保留**、**排除**、**待定**。
   保存期间所有写操作应暂时禁用；成功后状态立即可见，并自动前进到下一个未审阅事件。
3. 点击 **清除审阅**。预期该事件回到未审阅，峰顶位置不变。
4. 对一条已人工调整的事件点击 **恢复自动峰顶**。预期只恢复自动识别位置，原审阅状态
   不变。
5. 用 **撤销** 和 **重做** 恢复或重放上述操作。关闭应用后重新打开同一项目，检查状态、
   备注和撤销/重做历史仍然一致。

若保存失败，界面必须保留失败前的事件、选择和状态，并提供可操作的错误提示；不要在
不确定是否成功时重复快速点击。

## 6. 补充事件与重新定位峰顶

请在一次性项目中执行本节。

1. 点击 **添加遗漏峰**。模式栏应显示允许区间和键盘瞄准位置；移动鼠标只用于瞄准，
   单击图中有效区域才生成候选预览，不会立即修改项目。
2. 先按 Esc 取消一次。预期没有新增事件，也没有改变审阅状态。
3. 再次进入添加模式，在确有信号的位置生成预览。核对候选峰顶和变化信息后点击
   **应用候选**。若位置属于已有事件，应用应导航到已有事件而不是制造重复项。
4. 选择一个事件，点击 **重新定位峰顶**。只在页面显示的允许区间内选择候选；区间外、
   坐标轴、图例、标签或图外点击都不能修改项目。
5. 做一次纯键盘路径：进入模式后，焦点应落在“键盘瞄准位置”；用方向键微调，按 Enter
   生成预览，再按 Enter 应用，或按 Esc 取消。
6. 应用后检查核心证据随新峰顶更新。再测试撤销、重做和关闭重开。

## 7. 修改分析范围

范围应用会重新计算项目，请继续使用一次性项目或副本。

1. 点击顶栏 **项目设置**，打开 **修改分析范围**。
2. 填写新起止时间并点击 **计算影响**。计算中应显示进度且允许取消；取消后当前项目范围
   不变。
3. 预览完成后核对原范围、新范围，以及可直接沿用、移出范围、需要再确认、新识别和保留
   人工事件的数量。
4. 先按 Esc 或点击 **取消**。预期预览被放弃，工作区范围不变。
5. 再次计算同一范围，填写可选备注并点击 **应用新范围**。应用期间不能关闭或重复提交；
   成功后工作区刷新为新范围。
6. 关闭并重开项目，确认新范围和仍在当前范围内的审阅结果保持一致。

## 8. 两类导出

1. 点击顶栏 **导出结果**。默认选择 **审阅结果**，范围为当前分析范围，事件状态为仅已
   保留；只有明确勾选 **同时包含待定事件** 才可加入待定事件。
2. 选择一个新的 CSV 文件目标，填写可选备注并导出。完成后核对页面报告的名称、行数和
   提示，再抽查 CSV 内容是否符合筛选预期。
3. 再次打开导出窗口，切换到 **完整审计数据包**。此时“包含待定”选项应隐藏且不会沿用
   上次选择。选择一个独立目标目录并导出。
4. 导出进行中不能重复提交或关闭。失败时应保留项目原状态并显示可操作提示；成功后关闭
   并重开项目，审阅状态不得因导出而改变。

## 9. 原生显示与可访问性抽查

在本轮被指定的平台和缩放下，至少重做欢迎页、工作区和范围预览三种状态：

- 记录系统缩放和窗口所在显示器；跨显示器后文字与控件大小应随 DPI 正确更新；
- 检查长项目名、长中文提示、底部按钮、焦点环、滚动区域和对话框边界；
- 对话框打开时，Tab 焦点必须留在对话框内；关闭后应回到原入口；
- 颜色之外还应有形状、文字或状态标签帮助区分事件；
- 不应出现内容裁切、重叠、横向溢出或不可达操作。

浏览器缩放、响应式窗口或截图代理不能替代原生 DPI 验证。Windows 四档原生缩放证据已
齐备；macOS Retina 在获得 Apple Silicon 可见界面证据之前必须继续标记为待验证。

## 10. 验收记录

每个问题请记录：

- 候选版本、包 SHA-256、操作系统、显示缩放和显示器；
- 使用的安全显示名即可，不要在报告中粘贴个人绝对路径；
- 最短复现步骤、期望结果、实际结果和错误提示原文；
- 一张包含完整窗口和焦点位置的截图；
- 问题是否发生在写入前、保存中或保存完成后；
- 关闭并重开项目后的状态，以及源文件大小、修改时间和 SHA-256 是否保持不变。

建议按以下结论提交：**通过**、**有条件通过** 或 **不通过**，并列出阻断项与高优先级
问题。即使本轮没有发现问题，也只能说明本次环境和任务通过；在 macOS Retina 真实证据
与最终签收齐备前，不得宣称 Phase 2R 已退出。
