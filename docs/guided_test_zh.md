# MS Event Studio：本轮 Windows 快速复测

你已经确认 Windows 主流程没有问题，所以这次**不用再测新建项目、逐项审阅、导出、关闭重开，也不用修改显示缩放**。只复测本轮改过的信号图和“重新定位峰顶”，预计 3–5 分钟。

## 1. 启动最终版本

1. 打开 `dist\windows\MS-Event-Studio`。
2. 双击 `MS-Event-Studio.exe`，不要把 EXE 单独复制出去。
3. 打开一个你熟悉的项目。

## 2. 看信号图（约 1 分钟）

在图上随意移动鼠标，重点看这五件事：

- 峰顶时间是小号、透明背景的纯数字，不再有大白框，也不再显示 `min`；
- 鼠标放到不同位置时，图上显示的那组数字不会忽多忽少或换来换去；
- 小三角和圆点不会盖住真实峰形；
- “事件筛选”文字能正常看清；
- “上一事件 / 下一事件”和下面的“当前事件”之间有明显空隙，其他按钮也没有挤在一起。

说明：这里只要求**悬停不改变标签**。点击另一个峰属于切换当前事件；当前事件会优先显示，
在最多 8 个数字和防重叠规则下，附近的一个数字可能被替换。这是已知的非阻断行为。

## 3. 看“重新定位峰顶”有没有依据（约 2 分钟）

这个功能**只用于自动标记明显偏离真实局部峰顶的事件**，不是每个事件都要调整。

1. 最好找一个自动标记没有正好落在局部最高点的事件；找不到也没关系，任选一个自动事件看看界面即可。
2. 点击 **重新定位峰顶**。
3. 图应自动放大到该事件附近，并清楚显示真实局部曲线：
   - 两条青色虚线只是科学规则允许选择的范围；
   - 选择依据是曲线真正达到最高处的位置，不是凭感觉拖一个滑条；
   - 标记应足够小，不能遮住峰尖。
4. 点击你认为的真实峰顶（也可以用方向键微调后按 Enter），查看候选预览。
5. 预览阶段只应显示原位置、候选位置和偏移，不应再显示“当前瞄准”或十字光标。
6. 点击 **取消**。这次复测不用应用候选，不会改项目。

如果局部曲线仍看不清，或者你仍无法说明“为什么应该选这个点”，就算没有通过，请直接截图告诉我。
