# MS Event Studio Windows 人工验收操作卡

当前先验收 **Windows 版本**。Windows 没有通过前，不安排 macOS 验收。

这次只需要像普通用户一样用一遍软件，判断它是否好懂、顺手、可信。预计 10–15 分钟，
不含首次分析源文件的等待时间。

你不需要运行命令、计算哈希、查看 GitHub Actions、修改显示缩放、故意制造错误，也不需要
重新读取 7.38 GiB 大文件。

## 开始前

准备以下内容：

- 一份可以修改的 MS Event Studio 项目副本；优先使用它。
- 如果没有项目副本，准备一个中小型 MS TXT 文件和一个新的空项目位置。
- 一个用于保存测试 CSV 的位置。

不要使用唯一的生产项目。涉及保存、调峰和撤销的步骤都应在副本中完成。

## 1. 启动 Windows 程序

1. 在资源管理器中打开仓库的 `dist\windows\MS-Event-Studio` 文件夹。
2. 双击 `MS-Event-Studio.exe`。不要把 EXE 单独复制到别处运行。
3. 如果 Windows SmartScreen 阻止启动，点击 **更多信息 → 仍要运行**。

看到下面这些就算通过：

- 只出现一个 MS Event Studio 窗口；
- 欢迎页能看到 **新建项目** 和 **打开项目**；
- 没有黑色终端窗口、旧版 Tk 界面或第二个应用窗口。

如果程序打不开，到这里就停下并截一张完整屏幕图，不必继续排查。

## 2. 打开或新建项目

下面两种方式只选一种，优先选 A。

### A. 已有项目副本

1. 点击 **打开项目**。
2. 选择项目副本所在的文件夹。
3. 等待审阅工作区出现。

### B. 没有项目副本

1. 点击 **新建项目 → 选择文件…**，选择测试 TXT。
2. 等待分析完成；期间试着移动窗口，确认程序没有卡死。
3. 填写项目名，起点和终点保持在页面给出的可用范围内。
4. 点击 **选择位置…**，选择一个新的空位置，再点击 **创建项目**。

看到工作区、事件列表和峰形图就算通过。页面可以显示文件名，但不应展示一长串完整磁盘
路径。

## 3. 做两次审阅

1. 看左侧当前事件，再看右侧图中高亮的峰，确认二者明显对应。
2. 点击 **更多证据**，看看 PC34、m/z 和质量误差是否容易找到和理解。
3. 点击 **保留**。
4. 软件前进到下一个事件后，点击 **待定**。
5. 点击一次 **撤销**，再点击一次 **重做**。

通过标准：保存反馈清楚；保存后确实前进到下一个事件；撤销和重做的变化一眼可见。

## 4. 试一次峰顶调整

1. 选中一个自动事件，点击 **重新定位峰顶**。
2. 在图中允许的区间内点击邻近峰顶，查看候选预览。
3. 点击 **取消**，确认峰顶没有改变。
4. 再预览一次，这次点击 **应用候选**，然后点击 **撤销**。

通过标准：允许区间、候选位置、应用和取消都容易理解；第一次点击只预览，不会直接修改
项目；取消和撤销的结果符合直觉。

如果不知道该点哪里，或者进入编辑后看不出下一步该做什么，这也算需要反馈的问题，不必
反复尝试。

## 5. 预览范围并导出 CSV

1. 点击 **项目设置 → 修改分析范围**。
2. 小幅调整起点或终点，点击 **计算影响**。
3. 看完影响数量后点击 **取消**，不要应用新范围。
4. 点击 **导出结果**，保持默认的 **审阅结果**。
5. 选择一个新的 CSV 文件名并导出。

通过标准：范围预览能说清楚会发生什么；取消后项目范围不变；导出完成后，目标位置确实
出现 CSV，页面显示的文件名和行数也合理。

## 6. 缩放窗口并重开

1. 把窗口拖小，再恢复到较大尺寸。不要修改 Windows 的显示缩放设置。
2. 打开 **修改分析范围** 对话框并滚动到最底部。
3. 确认没有文字被截掉、按钮互相压住、横向滚动或模糊缩放，底部按钮可以点到。
4. 关闭软件，重新启动，再从最近项目中打开刚才的项目。

通过标准：刚才的 **保留/待定** 状态仍然存在；应用能正常关闭和重开，不残留第二个
窗口。
