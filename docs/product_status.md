## 两个科学参数的当前含义

### Primary marker m/z

- 默认值 `760.5851`；每个 scan 在该目标的闭区间 ±12 ppm 内取最大强度，形成随时间变化的
  primary trace，同时保留命中数量、强度和实测 m/z/ppm 证据。
- 自动检峰继续使用源自 LMA v0.4.4 的同一套自适应背景、峰高、显著度和最小扫描距离规则。
- 改 marker 会重新解析原始 MS，产生新的参数哈希、检测代次和自动事件；旧项目不会被静默重解释。
- `782.5616` 仍是固定的质量对照 marker，不参与自动事件生成。
- **验证边界**：默认 `760.5851` 通过四个大型真实 MS 文件回归，是当前唯一常规推荐；替代 marker
  只有合成提取测试，必须明确标为实验性。“算法能运行”不等于“这个离子适合作为细胞事件 marker”。

### 相邻事件提示阈值

- 默认值 `0.60 s`，允许范围 `0.01–60 s`。
- 自动峰按时间排序；对每个峰计算到前一个和后一个自动峰峰顶的时间差，取较小值：
  `nearest_gap = min(previous_gap, next_gap)`。
- 只有 `nearest_gap < threshold` 才标记“相邻事件距离较近”；恰好等于阈值不标记。
- 同一对近邻峰的两边都会被标记。阈值只影响质量提示和批量保留的跳过集合，
  不合并、不删除峰，也不改变自动事件身份。
- 检峰本身另有独立的最小峰距，primary trace 当前为约两个扫描间隔；不能把它与 `0.60 s`
  审阅阈值混为一谈。
- 原始自动风险来自项目创建时保存的自动事件证据。人工调峰不会改写它，因此检测器当时的结果
  永久可审计；人工补充事件的原始自动风险显示为“不适用”。
- 软件同时对全部当前 active events 的峰顶实时排序和计算近邻风险，不受当前筛选、审阅状态或
  可见窗口限制；人工调峰、添加事件、撤销或重做后会随新 workspace 重新派生。
- 批量保留对两项取逻辑或：原始风险或当前风险任一成立就跳过。界面分别显示两项，汇总中的
  分项计数可能重叠；提交时还会校验完整 active 事件快照，避免另一窗口的并发编辑被越过。

## 当前建议

- 普通项目继续使用 `760.5851` 和 `0.60 s` 默认值；`760.5851` 是唯一常规推荐，其他 marker
  一律按实验性设置对待。
- 在没有真实对照数据前，不把任意 marker 配置宣传为经过验证的常规能力；若要试验替代 marker，
  应新建独立项目并与人工事件判断或已知事件坐标比较。
- `0.60 s` 目前适合作为“不丢事件、只提醒人工看”的保守默认值。要优化它，应使用人工判定的
  近邻事件集合评估不同阈值下的提示数量和漏提示，而不是凭界面观感调整。
- marker 取窗、背景估计、检峰和两类相邻风险的数学解释见
  [marker m/z 的数学原理与验证边界](marker_mz_principles_zh.md)。

## 明确不做

- 不把 LMA v0.4.5 的外部事件坐标 CSV 辅助通道混入默认自动检测。
- 不开放 ppm、峰高、prominence 等专家参数的任意配置。
- 原生选择仍使用 token 授权；项目和原始文件路径仅作本机核对显示，显示路径不赋予任意文件访问权限。导出不得覆盖 LMA Studio 项目文件。
